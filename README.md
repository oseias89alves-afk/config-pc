# config-pc

Script PowerShell para configurar fuso horário e Chrome nas máquinas da empresa.

## 🚀 Como executar na máquina do cliente

Abra o **PowerShell como Administrador** e rode o comando abaixo:

powershell
iwr -useb https://raw.githubusercontent.com/oseias89alves-afk/config-pc/main/config-pc.ps1 | iex
